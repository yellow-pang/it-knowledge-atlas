# MVP

이 문서는 전체 MVP의 목표와 완료 조건이다. 현재 구현 상태는 아래와 같으며 전체 MVP 완료를 뜻하지 않는다.

| 항목 | 현재 상태 |
| --- | --- |
| 개념 목록·상세·관계 이동 | 다섯 개 개념의 정의, 30초 요약, 3분 설명과 출처·검토 상태를 표시하고 명시된 관계로 이동한다. 반응형 화면의 일부 동선을 확인했으며 실제 스마트폰의 전체 사용성 검증은 남았다. |
| 기술사 회상 | 개념별 일반 설명 과제를 생각한 뒤 핵심 키워드나 목차를 펼쳐 확인한다. 회상 내용은 저장하지 않는다. 공식 게시물의 버전과 문제지 링크를 표시한다. 격리 수준을 두 버전의 공식 기준 영역과 제137회 3교시 4번에 연결했다. AI가 원문을 대조했으며 기준 영역 연결은 해석이다. 독립 검토와 실제 스마트폰 학습 흐름 검증은 남았다. |
| 오늘의 학습·진도·복습·현황 | PostgreSQL 저장 기능과 마이그레이션을 구현했고 운영 DB에 복습 기록과 학습 상태가 저장된 것을 확인했다. 실제 스마트폰의 전체 동선과 운영 환경의 지속 사용은 미검증이다. |
| 콘텐츠 등록 | 로컬 Markdown 파일·폴더를 미리보기 후 명시적으로 등록한다. 검토용 초안과 기존 콘텐츠 검증을 지원하며 새 콘텐츠의 앱·DB 연계 흐름은 통합 검증이 남았다. [사용 안내](content-workflow.md)를 따른다. |
| 검색 | 미구현이다. 제목·별칭 검색은 아래의 MVP 계획이다. |

## 목표와 흐름

혼자 매일 실제로 사용할 수 있는 최소 학습 루프를 만든다. 오늘 화면에서 복습을 먼저 선택하거나 아직 학습하지 않은 개념을 열고 정의·원리를 읽는다. 화면 안내에 따라 기술사 관점의 핵심 키워드 3개 또는 설명 목차를 떠올리고 스스로 설명하는 것은 매 학습의 필수 단계다. 기억 상태를 저장하고 다음 날짜와 학습 현황을 확인한다. 검증된 시험 자료가 없어도 직접 작성한 일반 설명 과제로 회상하며 이를 기출문제로 표시하지 않는다.

첫 MVP는 온라인 우선이며 서버 연결이 필요하다. 연결이 없으면 읽기와 기록 저장을 보장하지 않고, 기록 저장 응답을 확인하지 못하면 안내하고 현재 화면에서 같은 요청을 재시도할 수 있다. 화면을 떠나거나 새로고침하면 요청 ID는 유지되지 않는다. 오프라인 읽기와 복습 기록 동기화는 후속 단계다.

## 기능별 최소 완료 조건

| 기능 | 완료 조건 |
| --- | --- |
| 오늘의 학습 | 예정일이 오늘이거나 이전인 복습과 미학습 개념을 구분해 표시한다. 데이터가 없거나 복습이 없을 때도 다음 행동을 안내한다. |
| 개념 상세 | 정의, 설명·원리, 출처와 검증 상태를 표시한다. 없는 선택 항목은 생략한다. |
| 개념 관계 | 관련 및 선행 개념을 구별하고 대상 상세로 이동한다. 끊어진 참조는 콘텐츠 검사에서 알려준다. |
| 복습 | 기억 상태를 선택하면 결과와 시각을 저장하고 다음 복습일을 계산해 보여준다. 새 개념도 첫 평가로 복습을 시작한다. |
| 기술사 회상과 연계 | 학습 화면이 매번 핵심 키워드 3개 또는 설명 목차를 떠올리도록 안내한다. 입력·저장은 필수가 아니다. 확인된 시험 영역 또는 적법하게 참조할 수 있는 문제는 출처와 함께 연결한다. 자료가 없으면 미확인을 표시하고 일반 설명 과제로 회상을 안내한다. |
| 학습 현황 | 학습한 개념 수, 예정된 복습 수, 분야별 학습 수와 전체 개념 수를 표시한다. 한 개념이 여러 분야에 속할 수 있어 분야별 합계는 고유 개념 수와 다를 수 있다. |

복습은 기억 상태 `다시`/`어려움`/`기억남`에 대해 평가일 기준 각각 1/3/7일 뒤를 예정일로 하는 고정 규칙을 사용한다. 날짜 경계는 서버의 명시적 `Asia/Seoul` 설정으로 처리하고 이력에는 실제 시각과 적용 규칙 버전을 저장한다. 개인화된 간격 반복은 아니다. 예정일 전이나 같은 날이라도 사용자가 의도적으로 다시 평가하면 새 이력을 남기고 마지막 평가일 기준으로 예정일을 다시 계산한다. 동일 요청의 재전송은 같은 요청 식별자로 중복 기록하지 않으며, 의도적인 새 평가는 새 식별자를 사용한다. 저장 실패를 표시하고, 실제 사용에서 조정 필요성이 확인되면 이력을 보존한 채 규칙을 버전 관리한다.

기술사 회상 안내는 필수지만 연습 내용을 앱에 입력·저장하는 기능은 필수가 아니다. 반복 작성 이력은 후속 단계에서 추가한다.

## 최소 데이터 저장과 검색

PostgreSQL에는 개인 진도와 복습 이력, 재전송 식별자를 저장한다. 개념·관계와 확인된 시험 자료는 Markdown 등 버전 관리 파일에서 읽으며 첫 MVP에 별도 콘텐츠 색인 테이블은 필수가 아니다. 제목·별칭을 포함한 소규모 목록 검색은 원본을 읽어 단순 비교하는 방식부터 검증한다. 본문 전문 검색, DB 기반 관계 검색, 검색 색인과 벡터 검색은 실제 필요와 자료 규모를 확인한 뒤 추가한다. DB가 없어도 개인 데이터가 안전하게 저장된 것으로 표시하지 않는다.

## 완료와 검증의 구분

- **기능 완료:** 자료가 없을 때 미확인을 표시하고, 확인된 자료가 있을 때 출처와 함께 연결하며 일반 설명 과제로 필수 회상을 안내한다.
- **실제 시험 연계 검증 완료:** 확인된 시험 영역이나 적법하게 참조할 수 있는 문제를 최소 한 건 확보해 실제 연결과 학습 흐름을 검증한다. 자료를 확보하지 못하면 기능은 완료할 수 있어도 실제 시험 연계 검증은 미완료로 보고한다. 원문 저장 권리가 불명확하면 링크와 식별 정보만 사용한다.

## 모바일 검증

시험 연계 화면은 데스크톱 Safari에서 두 기준 버전 펼치기, 회상 펼치기, 공식 기출문제 링크 이동과 최종 2027~2030 기준 영역 연결을 확인했다. Safari 반응형 모드 320×700에서 기준 영역 펼치기와 화면 배치를 확인했다. 별도 테스트 DB에서 시험 연계 상세 화면 조회 전후 복습 이력과 예정일이 유지됨을 확인했다. 운영 배포 후 사용자가 기본 사용에 문제가 없다고 확인했고 운영 DB의 기록 존재를 확인했다. 사용한 기기·브라우저와 스마트폰의 전체 동선, 콘텐츠 변경 전후의 전체 학습 흐름은 미확인이다.

2단계에서 Safari 반응형 모드로 320×700 목록과 375×812 상세 화면을 확인했다. 375×812에서 회상 내용 펼치기·Enter 키로 닫기와 선행 개념 이동을 확인했다. 이는 실제 스마트폰, 스크린리더 또는 전체 키보드 동선 검증을 대신하지 않는다. 개념 학습 기반은 이 상태로 마무리하고, 배포 후 스마트폰에서 확인해 발견한 문제를 이슈 등으로 기록하며 우선순위에 따라 점진적으로 개선한다.

전체 MVP 검증에서는 실제 스마트폰 브라우저에서 한 손 조작으로 오늘 화면 → 상세 → 관계 이동 → 키워드·목차 회상 → 자기 평가 → 저장 및 다음 복습일 확인을 수행한다. 좁은 화면에서 텍스트와 버튼이 잘리지 않고 확대·키보드/스크린리더 사용에도 핵심 동선이 유지되어야 한다. 서로 다른 3일에 학습하고 매일 저장 후 다음 복습일을 확인한다. 5~10분은 목표로 관찰하되 초과 자체를 실패로 처리하지 않고 시간이 걸린 지점을 기록한다. 새 콘텐츠·복습 없음과 연결 불안정·저장 실패도 확인한다. 오프라인 저장 성공으로 오인시키지 않는다.

## 운영 준비 확인

운영 DB에 기록이 생성된 상태다. 기능 완료와 별도로 다음을 확인한다. 백업과 복원은 데이터 보존을 위해 우선 진행한다.

- 개발 환경이 운영 DB를 가리키지 않는지 확인한다.
- 백업을 별도 경로에 복원해 최근 복습 기록을 확인한다.
- Mac mini 재시작 후 서비스와 데이터가 정상 동작하는지 확인한다.
- 기존 Tunnel을 통한 HTTPS 로그인과 미인증 접근 차단의 기본 동작은 확인했다. 실제 휴대폰에서 전체 학습 동선을 검증한다. 세부 요구사항은 [인증 전략 결정 기록](decisions/002-application-authentication.md)을 따른다.

백업 주기와 허용 가능한 데이터 손실량은 사용자가 정한다.

## 후속 기능과 제외 이유

서술형 답안 에디터·반복 기록과 비교, 시간제한 모의고사, AI 피드백·생성, 임베딩 추천, 외부 저장소 자동 수집, 외부 자료의 대량 수집·변환, 상세 통계, 다중 사용자는 실제 학습 루프 검증 이후에 다룬다. 초기에는 콘텐츠 신뢰성, 복습 저장 및 사용성보다 구현·유지 비용이 크다. 그래프 시각화도 목록 탐색이 부족하다는 근거가 생길 때 검토한다.
