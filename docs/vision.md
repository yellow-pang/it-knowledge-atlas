# 비전

## 왜 만드는가

실무 기술은 서로 연결되어 있지만 흩어진 메모를 다시 찾아 이해하고 설명하기는 어렵다. 이 프로젝트는 하나의 개념 원본을 일반 IT 학습과 기술사 준비에서 함께 사용하고, 짧은 회상과 반복을 통해 이해를 오래 유지한다. 정보관리기술사를 우선하되 다른 시험 종목도 같은 개념을 재사용한다. 공식 분류 및 문제는 근거를 확인할 때만 연결한다.

세 번째 목표는 개인 플랫폼을 직접 설계·개발·운영하며 아키텍처, 데이터베이스, 검색, 인덱싱과 AI 등 실무 기술을 배우는 것이다. 기술은 실제 필요에 따라 단계적으로 도입하며 개발 자체가 목표가 되어 일상적인 IT 학습과 장기적인 기술사 대비를 희생하지 않는다. 기술사 준비는 장기 목표이며 단기 합격을 위한 과도한 시험 기능을 MVP에 넣지 않는다.

## 매일의 학습

이동 중 앱을 열면 복습 대상과 새 개념을 보고 하나를 고른다. 정의와 원리를 읽고 관련·선행 개념을 살펴본 다음, 기술사 관점에서 핵심 키워드 3개 또는 설명 목차를 떠올리고 스스로 설명한다. 이 회상은 매 학습의 필수 단계이며 입력·저장은 선택이다. 검증된 시험 자료가 없으면 직접 작성한 일반 설명 과제로 연습하며 기출문제로 표시하지 않는다. 기억 상태를 기록하고 다음 복습일을 확인한다. 전체 흐름은 5~10분을 목표로 하되 학습량을 강제하지 않는다.

첫 MVP는 온라인 우선이며 서버 연결이 필요하다. 이동 중 사용과 연결 없는 사용은 다르다. 연결이 없으면 읽기와 기록 저장을 보장하지 않으며 저장되지 않은 상태를 알린다. 오프라인 읽기와 복습 기록 동기화는 후속 단계다.

## 지속과 확장

작은 개념 단위와 의미 있는 관계를 수동으로 관리하고, 실제로 참고한 출처와 검증 상태를 남긴다. 처음에는 소수의 검토된 콘텐츠로 흐름을 확인한 뒤 필요에 따라 분야와 문제를 확장한다. 누락된 항목을 채우기 위해 근거 없는 콘텐츠를 만들지 않는다. 실무 분석은 별도 `yelloh-pang-lab`에 두고 필요할 때 링크한다.

## 성공 기준

- 실제 스마트폰에서 학습과 필수 회상, 복습 저장을 수행하며 5~10분을 사용성 목표로 관찰한다.
- 서로 다른 3일에 재방문해 저장과 다음 복습일을 확인한다.
- 실제 시험 연계 검증은 확인된 시험 영역 또는 적법하게 참조할 수 있는 문제를 최소 한 건 확보해 개념에서 출처와 연결로 이동하고 학습 흐름을 수행했을 때 완료한다. 자료가 없으면 안전한 미확인 표시 기능을 완성할 수 있지만 실제 연계 검증은 미완료다.
- 사용자가 콘텐츠 수정과 데이터 백업·복구를 이해하고 수행할 수 있다.

이는 개인 사용을 통한 검증 목표이며 합격이나 학습 효과를 보장하는 지표는 아니다.

## 비목표

초기에는 다중 사용자, 소셜 기능, 대규모 콘텐츠 수집, 자동 생성·평가, 복잡한 그래프 시각화와 모의고사 플랫폼을 만들지 않는다. 공식 출제기준을 임의로 재구성하거나 외부 교재를 무단 복사하지 않는다.
