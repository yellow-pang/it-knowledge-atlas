# 학습 콘텐츠 이용 안내

`content/concepts/`에는 학습 개념을, `content/exams/`에는 공식 시험 자료의 출처·식별 정보와 연결을 기록합니다. 이 디렉터리의 자료에는 저장소의 앱 코드에 적용한 [Apache License 2.0](../LICENSE)을 적용하지 않습니다.

직접 작성한 학습 콘텐츠에 대한 별도 공개 라이선스는 아직 정하지 않았습니다. 별도 허락이나 명시된 조건이 없는 한 이 안내는 콘텐츠의 복제·수정·재배포 권한을 부여하지 않습니다. AI 작성 보조 여부와 기술 내용의 검증 상태는 각 콘텐츠에서 별도로 확인합니다.

Q-Net을 비롯한 제3자의 자료는 해당 권리자와 자료별 이용 조건을 따릅니다. 현재 시험 자료는 문제 전문이나 PDF를 포함하지 않으며 공식 링크·식별 정보와 일부 출제기준 항목명을 기록합니다. 항목명과 자료별 이용 범위는 별도 확인이 필요합니다. 원문·문제지·이미지 등을 추가하기 전에는 이용 조건과 필요한 허락을 확인하고, 확인되지 않으면 원문을 복제하지 않습니다. [Q-Net 저작권 안내](https://mo.q-net.or.kr/rcv002.do?gId=&gSite=Q&gTitle=&id=rcv002_baseInfo&rcvPFlag=Y)

콘텐츠의 검토·등록 방법은 [콘텐츠 관리 안내](../docs/content-workflow.md)를 따릅니다.
